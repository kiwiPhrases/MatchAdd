A 1P/2P player matching and memory-matching game to match small digit add operations to their sums (ie match 1+2 to 3)

**Key Features**

- Timer on the matching game allows the little one to see if they can improve their matching skills with each game
- Healthbar in matching and memory games places a cost on misses; thus, discouraging pure guessing
- 2-player option allows munchkins to challenge themselves against their peers and parents
- Neon colors, because why not.

*Other potentially interesting elements*

- No data retention except for session information for leaderboard
- It does have sounds so just beware
